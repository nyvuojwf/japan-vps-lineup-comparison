## 先問自己：你要的是低延遲，還是日本 IP？

這兩個目標常常被混在一起，但採購邏輯不同。

如果你只是想要「中國大陸與台灣用戶打開網站快」，東京不是最佳解，香港才是。整理多份線路測試資料後，常見的落差大概是這樣：

| 機房地點 | 中國大陸三網延遲（走優化線路） | 相對成本 |
| --- | --- | --- |
| 香港 | 約 20–50ms | 最高 |
| 日本東京 | 約 50–90ms | 次高 |
| 美國洛杉磯 | 約 150–180ms | 較低 |

實際數字會隨你的 ISP、時段和路由跳數變化，不是保證值。重點是東京卡在香港與洛杉磯之間：比洛杉磯快一大截，又比香港便宜。

反過來說，如果你的需求本身就是「需要一個日本 IP」——日區電商後台、跨境帳號註冊、日本本地服務串接、需要日本節點的中轉架構、或者只是想測試日本使用者看到什麼——那東京就是唯一答案，跟延遲高低無關。這種情況下，你要挑的是線路品質，而不是最低月付。

## 該買 Pro 還是 T1？幾個具體判斷

不用糾結「哪個比較好」，看你的使用情境。

**選 TYO.Pro 的情況：**
- 服務對象主要是中國大陸或台灣使用者，需要晚高峰不掉速
- 要當正式生產環境，跑網站、API、資料庫，不能接受月流量到頂就停機
- 需要低丟包的跨境連線，例如遠端桌面、資料同步、遊戲加速

**選 TYO.T1 的情況：**
- 需求只是「一個日本 IP」，例如測試環境、帳號註冊、東南亞或日本本地用戶的落地節點
- 用量大但預算有限，寧可流量超了被限速也不要自動停機
- 當跳板或中轉節點，真正對外的最佳化線路由其他機器負責

單純就價格效率來說，如果你的用戶在中國大陸、又必須用日本 IP，Pro.TINY 的 $21.90 是這個組合的最低門檻；但 500GB 月流量對影片或大檔案傳輸其實偏緊，跑滿一兩個月就會想升級到 STARTER。反過來，如果你只是要一個日本節點做測試，T1.WEE 年付 $36.90 的單位成本比任何 Pro 機型都低太多，買 Pro 就是浪費。

## 從註冊到下單，幾個實際會卡住的點

1. **註冊時把代理關掉**。用不乾淨的 IP 或明顯假的資料註冊，會觸發風控，訂單可能被自動退款，處理起來反而更麻煩。
2. **庫存是浮動的**。東京 Pro 系列長期處於補貨節奏，常常是釋放一批 IP 才開放一批名額。看到有貨就別拖，等下次補貨的間隔不確定。
3. **付款方式**。支付寶、微信支付、PayPal 都支援，對沒有國際信用卡的人來說門檻低。
4. **Windows 系統**。4GB 記憶體以上的機型才適合自己裝 Windows，低配機型別勉強。
5. **串流解鎖別當成主要購買理由**。有整理文提到 Pro 線路對部分日本串流平台的解鎖表現不錯，但這類結果會隨平台政策與 IP 段變化，今天能解不代表續約後還能解。

## 常見問題

**Q：日本 VPS 推薦一定要選 CN2 GIA 嗎？**

不一定。CN2 GIA 的價值在「中國大陸用戶的體感」，如果你的使用者不在中國大陸，或者你只需要日本 IP 本身，多付的錢換不到相對應的效益。

**Q：東京 Pro 常常沒貨，怎麼辦？**

這是常態。可以先用 T1 系列把服務跑起來，等 Pro 補貨再遷移；也可以考慮同廠商的香港或洛杉磯機房過渡，但延遲特性不同，不是直接等價替換。

**Q：T1 系列的流量超了會怎樣？**

降速繼續跑，不會停機。WEE 降至 50Mbps，TINY、STARTER、MINI 降至 100Mbps，往上依機型到 200Mbps、500Mbps、1Gbps 不等。這是 T1 相對 Pro 最實用的一點差異。

**Q：有沒有官方測試 IP 可以先 ping？**

有。日本 CN2 GIA 線路可測 `154.12.190.32`，日本國際線路可測 `154.31.112.5`。自己從常用 ISP 打幾輪，比看任何人的測試截圖都準。
